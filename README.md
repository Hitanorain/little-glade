# 小小林间 · Little Glade

仿 Tiny Glade 美术风格的浮岛建造小游戏，单个 HTML 文件，用 three.js 渲染。

在线玩：https://hitanorain.github.io/little-glade/

## 玩法

- 四套场景风格可选：田园、魔法、未来、和风（日式庭园），左上角还能“随机地形”和切换岛屿大小（小 / 中 / 大）

- 左键拖拽建造：城墙（两端自动长出塔楼）、房屋、小路、栅栏
- 刷树木（10 种北美森林树种，含巨杉）、花丛（12 种野花）、岩石
- 像铺路一样涂抹水域，多笔自动连成一片，水深可选浅 / 中 / 深；可以放鱼
- “调整”工具：推拉城墙、栅栏、小路的形状
- 右上角切换时辰、天气（晴 / 阴 / 雷雨 / 雪）和四季
- 右键旋转视角，Shift+右键或中键平移，滚轮缩放，Ctrl+Z 撤销

## 本地运行

需要用本地服务器打开（模块从 CDN 加载）：

```
python -m http.server 8000
```

然后访问 http://localhost:8000/
